# Routes And Flows

## 공통 진입점

### `/`

- 파일: `src/app/page.tsx`
- 로그인 상태면 환영 메시지와 주요 기능 링크를 보여준다.
- 비로그인 상태면 로그인/회원가입 CTA를 보여준다.

### `/login`

- 파일: `src/app/login/page.tsx`
- 아이디/비밀번호 입력
- 토큰 발급
- 회원 상세 조회
- `AuthProvider.login()` 호출
- 홈으로 이동

### `/signup`

- 파일: `src/app/signup/page.tsx`
- 아이디 중복 확인
- 이메일 중복 확인
- 선택 이미지 base64 변환
- 회원가입 요청
- 성공 시 로그인 화면으로 이동

## 사용자 도메인

### 도서

- `/books`
  - 검색어 + 페이지 번호로 목록 조회
- `/books/[id]`
  - 도서 상세 조회
  - 로그인 사용자 대여 신청

### 공지

- `/notices`
  - 공지 목록 조회
  - `topFixed` 공지는 강조 표시
- `/notices/[id]`
  - 본문과 첨부 이미지 출력

### 문의

- `/inquiries`
  - 문의 목록 조회
  - 비밀글은 작성자/관리자만 링크 노출
- `/inquiries/new`
  - 로그인 사용자만 작성 가능
- `/inquiries/[id]`
  - 본문과 답변 목록 출력

### 행사

- `/events`
  - 행사 목록 조회
  - 로그인 사용자 신청 가능
  - 신청 후 재조회로 잔여 인원 갱신

### 마이페이지

- `/mypage`
  - 프로필 요약과 하위 메뉴 제공
- `/mypage/edit`
  - 이름/이메일/지역 수정
  - 선택 시 프로필 이미지 별도 업로드
- `/mypage/rentals`
  - 내 대여 이력 조회
  - 반납/연장 실행

### 시설예약

- `/facility`
  - 예약 신청 폼
  - 내 예약 현황
  - 상태/날짜 필터
  - 대기중 예약 취소

## 관리자 도메인

### `/admin`

- 관리자 메뉴 링크 허브

### `/admin/members`

- 전체 회원 조회
- 회원 삭제

### `/admin/books`

- `books` 탭
  - 도서 등록
  - 도서 수정
  - 상태 변경
  - 삭제
- `rentals` 탭
  - 전체 대여 기록 조회
  - 상태 필터
  - 반납/연장

### `/admin/notices`

- 공지 등록
- 키워드 검색
- 수정 모달
- 삭제

### `/admin/inquiries`

- 전체/답변대기/답변완료 필터
- 문의 본문 확인
- 인라인 답변 등록
- 삭제

### `/admin/events`

- 행사 등록
- 검색
- 수정 모달
- 삭제

### `/admin/facility`

- 전체 예약 조회
- 신청자/상태/시설 종류 필터
- 승인/반려
- 수정 모달
- 삭제
